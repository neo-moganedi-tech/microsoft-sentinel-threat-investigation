# Investigation Screenshots

## Overview

This directory contains screenshots captured during the Sentinel Threat Investigation Lab

The screenshots provide visual evidence of the KQL queries executed and the investigation results obtained using Azure Data Explorer

## Screenshot Evidence

| Filename | Description |
|---|---|
| `01-Azure-Data-Explorer-Environment.png` | Shows the Azure Data Explorer environment, help cluster and Samples database |
| `02-Security-Event-Analysis.png` | Shows the initial Windows security event analysis and query results |
| `03-Brute-Force-Detection.png` | Shows the detection of repeated failed authentication attempts |
| `04-Successful-Login-Correlation.png` | Shows the correlation between failed and successful authentication events |
| `05-Suspicious-PowerShell-Investigation.png` | Shows the investigation of potentially suspicious PowerShell execution |

## Evidence Collection

Screenshots were captured during the practical exercises using the Windows Snipping Tool

Each screenshot corresponds to a specific investigation exercise and supports the findings documented in the incident investigation report

## Investigation Environment

- Platform: Microsoft Azure Data Explorer
- Cluster: `help`
- Database context: `Samples`
- Query language: Kusto Query Language (KQL)
